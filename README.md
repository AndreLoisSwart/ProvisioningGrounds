# ProvisioningGrounds

A self-directed Data Engineering bootcamp — built in the open, learned by doing.

## Why

I'm an Integration Engineer with 12 years in IT and a deep background in SQL, ETL,
and API integration. This repo is a structured program to build the areas I need
for Data Engineer roles: modern Python depth and Infrastructure as Code
(Terraform), layered later with Azure, Databricks, and PySpark.

It's designed to be a project in its own right, not a folder of throwaway
scripts — the plan, the code, and the progress log all live here.

## How it works

Every exercise is a real problem, not an abstract kata, worked in a mentor-led
format: understand the task and the tools, attempt it unaided, review, revise.
The full teaching contract is in [CLAUDE.md](CLAUDE.md).

## Structure

Four phases, ramping from fundamentals to a full end-to-end pipeline:

1. **Python foundations** — the language, standard library, tests, real programs
2. **Working Python + first IaC** — Terraform fundamentals, Python against a database
3. **Pipeline engineering** — ingestion, data quality, orchestration
4. **Cloud + Spark** — Azure, Terraform on Azure, PySpark, Databricks, a capstone

Live status, the module map, and a log of completed exercises are in
[PROGRESS.md](PROGRESS.md).

## Tech covered

Python · pytest · Terraform · PostgreSQL · Azure (ADLS, ADF) · Databricks ·
PySpark · Kafka
