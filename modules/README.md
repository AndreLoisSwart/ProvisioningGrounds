# Modules

One folder per bootcamp module, named `mNN-slug`. The forward-looking module map
and status live in [`../PROGRESS.md`](../PROGRESS.md); this folder holds the work
itself.

## Per-module layout

```
mNN-slug/
  README.md      # what the module covered, what was built, key takeaways
                 # (written when the module wraps, not before)
  exercises/     # NN-slug.md — the brief for each exercise (task / tools /
                 # how they work), captured after it's delivered live
  src/           # the actual code — attempts and final versions
```

Content is built just-in-time, one module at a time. The live teaching happens in
conversation; the files here are the durable record and portfolio surface.
